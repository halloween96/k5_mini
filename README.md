# 국토 자전거 종주길 정보 공유

> 국토종주 자전거길 정보를 제공하고 이용자 간 후기를 공유할 수 있는 웹 서비스

## 프로젝트 개요

국토종주 자전거길을 이용하는 사용자에게 자전거길의 상세 정보와 
이용 후기를 제공하는 웹 서비스를 개발했습니다.

비회원은 자전거길 정보와 상세 내용을 조회할 수 있으며,
회원은 로그인 후 자전거길 이용 후기를 작성하고 수정할 수 있습니다.

### 프로젝트 목적

- 국토종주 자전거길 정보의 편리한 조회
- 자전거길별 상세 정보 제공
- 사용자 후기 작성 및 공유
- 회원 인증을 통한 게시글 작성 및 수정

## 주요 구현

### 1. 자전거길 데이터 조회

Backend API를 통해 자전거길 데이터를 조회하고,
API에서 전달받은 데이터를 React 컴포넌트에 전달하여
자전거길 목록을 동적으로 렌더링했습니다.

### 2. 로그인 토큰 관리

게시글 작성 및 수정 등 여러 기능에서 로그인 토큰이 필요하기 때문에
Recoil Atom을 활용하여 로그인 토큰을 관리했습니다.

게시글 작성 및 수정 요청 시 저장된 토큰을
Authorization 헤더에 포함하여 Backend API로 전달했습니다.

### 3. 지도 구현

자전거길의 위치 정보를 직관적으로 확인할 수 있도록
OpenLayers를 활용하여 지도 레이어를 구성했습니다.

Backend에서 전달받은 좌표 데이터를 지도에서 사용할 수 있도록 변환하고,
자전거길 상세 페이지에서 해당 위치를 확인할 수 있도록 구현했습니다.

### 4. 컴포넌트 재사용

자전거길 목록에서 동일한 형태의 정보가 반복적으로 표시되기 때문에
자전거길 정보를 표시하는 카드를 공통 컴포넌트로 분리했습니다.

Props를 통해 자전거길 이름, 코스, 거리, 예상 시간,
난이도 등의 데이터를 전달하여 동일한 UI를 재사용할 수 있도록 구현했습니다.

### 5. 페이지 라우팅

서비스의 각 화면을 URL에 따라 구분하고
페이지 간 이동을 관리하기 위해 React Router를 활용했습니다.

자전거길 상세 정보와 게시글 상세 페이지는 URL Parameter를 활용하여
선택한 데이터의 상세 내용을 조회하도록 구현했습니다.
