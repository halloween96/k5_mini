# 국토 자전거 종주길 정보 공유
> 국토종주 자전거길 정보를 제공하고 이용자 간 후기를 공유할 수 있는 웹 서비스

## 프로젝트 개요

국토종주 자전거길을 이용하는 사용자에게 자전거길의 상세 정보와 
이용 후기를 제공하는 웹 서비스를 개발했습니다.

비회원은 자전거길 정보와 상세 내용을 조회할 수 있으며,
회원은 로그인 후 자전거길 이용 후기를 작성하고 수정할 수 있습니다.

### 프로젝트 목적

- 국토종주 자전거길 정보의 편리한 조회
- 자전거길별 상세 정보 제공
- 사용자 후기 작성 및 공유
- 회원 권한에 따른 후기 작성 및 수정 기능 제공

## 기술 스택

### Frontend
- React
- JavaScript
- HTML5
- CSS3

### Backend

- H2

### Collaboration
- Git
- GitHub

## 주요 기능

### 자전거길 정보 조회
- 국토종주 자전거길 목록 조회
- 자전거길 선택 시 상세 정보 제공
- 비회원도 자전거 길 정보 조회 가능

### 회원 관리
- 로그인
- 회원가입
- 중복 계정 확인

### 후기 관리
- 로그인 사용자 후기 작성
- 작성한 후기 수정
- 사용자 권한에 따른 후기 수정 제한
